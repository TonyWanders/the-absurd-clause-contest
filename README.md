A program that writes one absurd clause, buried deep inside a
terms-of-service agreement, to `/output/entry.txt`, for the make.fun
competition
[The Absurd Clause Contest](https://make.fun/bounty/u-donrulezz-the-absurd-clause-contest-035cc0f1).

Run it with Python 3:

```
python3 main.py
```

It writes the clause below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The clause is 131 characters, inside the 1 to 200 gate.

## The clause

```
The Company reserves the right to name one (1) of your future pets, which shall answer to that name in all official correspondence.
```

Why this clause: it opens exactly like real legal boilerplate, a
reservation of rights with the classic numbered "(1)", then quietly
claims the right to name one of your future pets, and lands a second
absurd beat by making the pet answer to that name in all official
correspondence. No em dash, one sentence, nothing explained.
